# Как прошить Pixhawk 2.4.8 и менять настройки

Пошагово: что скачать, как подключить к компьютеру, как залить прошивку и как править параметры.

---

## 1. Что понадобится

### Железо

- Контроллер **Pixhawk 2.4.8**
- Кабель **USB micro-B** (часто в комплекте) — в порт **MICRO USB** на плате (не TELEM)
- Компьютер с Windows (проще всего) или Mac/Linux
- Модуль питания / батарея **не обязательны** для прошивки по USB (плата питается от USB)

### Программы (выберите одно)

| Программа | ОС | Для чего |
|-----------|-----|----------|
| **[Mission Planner](https://ardupilot.org/planner/docs/mission-planner-installation.html)** | Windows (рекомендуется) | Прошивка ArduPilot, калибровки, параметры |
| **[QGroundControl](https://qgroundcontrol.com/)** | Windows / Mac / Linux / Android | То же + удобно для PX4 |
| Драйвер USB | Windows | Обычно ставится вместе с Mission Planner (CDC/ACM) |

Для этой инструкции ниже — **Mission Planner + ArduCopter** (самый частый вариант для Pixhawk 2.4.8).

---

## 2. Установка Mission Planner

1. Скачайте установщик с официальной страницы ArduPilot (Mission Planner).
2. Установите, запустите **от имени администратора** при первой настройке (по желанию).
3. При первом подключении Windows может установить драйвер COM-порта — дождитесь окончания.

---

## 3. Подключение к компьютеру

1. На плате найдите разъём **MICRO USB** (обычно сбоку, подписан `USB` / рядом с слотом SD).
2. Воткните кабель в Pixhawk и в USB-порт ПК.
3. На плате должен загореться светодиод питания.
4. В Mission Planner в правом верхнем углу:
   - в списке портов выберите **COMx** (тот, что появился после подключения);
   - скорость: **115200** (часто подходит и Auto);
   - пока **не** жмите Connect, если идёте сразу прошивать «чистую» плату — для Install Firmware Connect не обязателен.

**Если COM-порт не появился**

- смените кабель (нужен кабель с линиями данных, не «только зарядка»);
- другой USB-порт (лучше USB 2.0 напрямую в ПК);
- Device Manager → Ports — есть ли неизвестное устройство;
- переустановите Mission Planner / драйверы.

---

## 4. Прошивка «мозгов» (Install Firmware)

> Прошивка **стирает** старые параметры полётного стека. Сохраните `.param` заранее, если плата уже настроена.

1. В Mission Planner откройте вкладку **Setup** (слева вверху: Initial Setup).
2. Выберите **Install Firmware**.
3. Выберите тип аппарата, например:
   - **ArduCopter V4.x** → Quad / Hex и т.д. под вашу раму  
   (для файлов из этого репозитория — **Copter / Quad**).
4. Если спросят плату — укажите **Pixhawk** / **FMUv2** / Pixhawk 1 (2.4.8 относится к этому семейству).
5. Начнётся загрузка файла прошивки с сервера, затем запись в контроллер.
6. Дождитесь сообщения об успехе. Не отключайте USB во время записи.
7. После прошивки плата перезагрузится (мигание светодиодов — норма).

### Если прошивка не идёт (bootloader)

1. Отключите USB.
2. Зажмите кнопку **Safety** (если есть) или переведите в DFU по инструкции к клону — у оригинального Pixhawk обычно достаточно USB.
3. Для многих клонов 2.4.8: подключите USB, в Mission Planner снова **Install Firmware**; при запросе «wait for board» подождите до 30–60 с.
4. Альтернатива: QGroundControl → Firmware → подключить плату когда попросит.

---

## 5. Первое подключение после прошивки

1. Выберите COM-порт, baud **115200**.
2. Нажмите **Connect** (правый верхний угол).
3. HUD должен показать горизонт, напряжение (если есть power module), статус GPS и т.д.
4. Если Connect не проходит — попробуйте baud **57600**, другой кабель/порт.

Сразу после чистой прошивки сделайте калибровки (раздел Setup):

1. **Mandatory Hardware → Accel Calibration** — акселерометр (положите плату всеми сторонами по подсказкам).
2. **Compass** — калибровка компаса (вращайте раму в воздухе, вдали от металла).
3. **Radio Calibration** — подключите приёмник и пульт, двигайте стики.
4. **Flight Modes** — назначьте режимы на тумблер канала 5 (или другой).
5. **Esc Calibration** — только если ESC требуют калибровки газом (пропеллеры сняты!).

---

## 6. Как менять настройки (параметры)

### Способ A — удобные экраны (рекомендуется новичкам)

1. **Connect** к плате.
2. Вкладка **Config / Tuning** (или Setup → Optional Hardware / Basic Tuning).
3. Меняйте понятные блоки:
   - Frame Type — тип рамы;
   - Battery Monitor — тип АКБ / делитель;
   - Failsafe — поведение при потере сигнала;
   - Flight Modes — режимы на тумблеры.
4. После правок параметры обычно пишутся сразу; для надёжности: **Write Params** / переподключите плату.

### Способ B — полный список параметров

1. **Config / Tuning → Full Parameter List** (или Full Parameter Tree).
2. Найдите параметр по имени (поиск), например `RTL_ALT`.
3. Введите новое значение → Enter.
4. Нажмите **Write Params**.
5. Для части параметров нужна **перезагрузка**: Disconnect → питание/USB снять-надеть → Connect.

### Способ C — загрузка готовых файлов из этого репозитория

1. Connect.
2. **Full Parameter List → Load** (или Load from file).
3. По очереди загрузите:
   1. `params/quad-x-baseline.param`
   2. `params/failsafe-gps.param`
   3. `params/tuning-soft.param`
4. **Write Params**.
5. Перезагрузите контроллер.
6. Проверьте критичные значения под свою батарею (`BATT_LOW_VOLT` и т.п. в `failsafe-gps.param` — там пример под 4S).

### Как сохранить свои настройки на ПК

**Full Parameter List → Save** — получите `.param` бэкап. Делайте перед каждой крупной прошивкой.

---

## 7. Краткая схема «с нуля»

```
Скачать Mission Planner
        ↓
USB-кабель → MICRO USB на Pixhawk
        ↓
Setup → Install Firmware → ArduCopter (Quad)
        ↓
Connect (COM, 115200)
        ↓
Калибровки: Accel → Compass → Radio
        ↓
Загрузить .param / править Full Parameter List → Write Params
        ↓
Чеклист перед полётом (checklist.md)
```

## 8. Частые ошибки

| Симптом | Что проверить |
|---------|----------------|
| Нет COM-порта | Кабель «только зарядка», драйвер, другой USB |
| Firmware upload failed | Стабильный USB, антивирус, повторить; версия MP свежая |
| Connect, но «No heartbeat» / «Последовательность не содержит элементов» | См. раздел 8.1 ниже |
| Не армится | `ARMING_CHECK`, компас, GPS, safety switch, калибровки |
| После Load «всё сломалось» | Вернуть Save-бэкап; не мешайте ArduPilot-параметры с PX4 |

### 8.1. Ошибка Connect: «Последовательность не содержит элементов»

Типичный стек:

```text
Последовательность не содержит элементов
   в System.Linq.Enumerable.Aggregate...
   в MissionPlanner.MAVLinkInterface.OpenBg...
```

**Смысл:** Mission Planner открыл COM/порт, но **не получил MAVLink heartbeat** от платы. Это не «поломка Windows», а «мозги молчат» (нет/битая прошивка, неверный порт, bootloader, питание).

**Что делать по порядку**

1. **Disconnect**, закройте другие программы, которые могут держать порт (QGC, другой MP, терминал).
2. В диспетчере устройств Windows посмотрите, какой **COM** появляется при подключении USB Pixhawk. В MP выберите **именно его**, baud **115200**.
3. Убедитесь, что кабель в разъём **MICRO USB** на плате (не TELEM1/TELEM2).
4. **Не жмите Connect**, пока нет прошивки. Сначала:
   - Setup → **Install Firmware** → ArduCopter (Quad) → Pixhawk / FMUv2;
   - дождитесь «Done» / успешного сообщения;
   - подождите 10–15 с после мигания светодиодов;
   - только потом Connect.
5. Если прошивка «висит» или Connect снова падает:
   - отключите USB на 5 с, подключите снова;
   - повторите Install Firmware;
   - попробуйте **QGroundControl → Firmware** тем же кабелем (часто стабильнее на клонах 2.4.8).
6. На части клонов Pixhawk 2.4.8 USB один не тянет стабильно: подключите **модуль питания + АКБ** (осторожно, пропеллеры сняты), затем снова Connect по USB.
7. Попробуйте baud **57600** и **1500000** (редко нужно на USB, но на клонах бывает).
8. Обновите Mission Planner до свежей стабильной сборки с ardupilot.org / GitHub releases (пути `C:\Users\...\CubePilot\MissionPlanner\` часто означают кастомную/старую сборку CubePilot — поставьте официальный MP параллельно и проверьте).

**Признаки, что прошивка живая:** после Connect HUD показывает горизонт, внизу идут пакеты, в Data есть Flight Data без окна Aggregate-ошибки.

**Если Status: `ERROR: No Response from board`**

Плата на COM видна, но bootloader не отвечает. Connect бесполезен, пока прошивка не запишется.

1. Закройте QGC и другие копии MP. В диспетчере устройств при подключении USB должен появляться/меняться COM — запомните номер.
2. Другой **data**-кабель и порт USB 2.0 напрямую в ПК (не хаб, не «только зарядка»).
3. На экране Install Firmware: **Force Bootloader** → сразу (за 2–3 с) клик по **Copter** → Platform **`Pixhawk1-1M`**.
4. Если снова No Response: отключите USB → зажмите кнопку **Safety** на Pixhawk → воткните USB, держите 2–3 с → отпустите → сразу снова Copter / `Pixhawk1-1M`.
5. Подключите **POWER + АКБ** (пропы сняты) + USB и повторите Force Bootloader → Copter.
6. Прошейте через **QGroundControl → Firmware** (часто лучше видит bootloader на клонах 2.4.8).
7. Поставьте официальный Mission Planner с ardupilot.org вместо сборки `CubePilot\MissionPlanner`.
8. Выньте microSD на время прошивки и повторите.
9. Если устройство в диспетчере «Unknown» / без COM — переустановите драйвер USB (Mission Planner / STM32 VCP), перезагрузите ПК.

Пока Status не покажет успех прошивки, ошибка Aggregate/Connect будет повторяться.

**Если ошибка остаётся после Install Firmware**

1. Убедитесь, что внизу в **Status** было явное сообщение об успехе прошивки (не пусто и не Error). Если успеха не было — Connect бесполезен.
2. В диалоге Platform берите **`Pixhawk1-1M`** (не `*-bdshot`). Запасные: `fmuv2` → `Pixhawk1` → `fmuv3`.
3. На экране Install Firmware снизу нажмите **Force Bootloader**, затем снова клик по иконке **Copter** (квад) → снова `Pixhawk1-1M`.
4. Отключите USB на 10 с, подключите, повторите прошивку **до** Connect.
5. Поставьте официальный Mission Planner с ardupilot.org (сборка из `CubePilot\MissionPlanner` часто капризна на клонах) **или** прошейте через **QGroundControl → Firmware**.
6. Подключите питание через **POWER + АКБ** (пропы сняты) и USB одновременно, снова Connect.
7. Проверьте светодиоды: после удачной прошивки обычно ритмичное мигание (не «мертвая» плата и не вечный режим только bootloader без реакции на Connect).

---

## 9. QGroundControl (кратко)

Если удобнее QGC:

1. Установите QGroundControl.
2. Подключите USB → плата обычно находится сама.
3. Меню прошивки (Vehicle Setup → Firmware) → выберите ArduPilot Copter или PX4.
4. Параметры: Vehicle Setup → Parameters — поиск по имени, Apply / Save.

Файлы `.param` из папки `params/` рассчитаны на **ArduPilot** в формате Mission Planner.
