# Чеклист перед первым полётом (Pixhawk 2.4.8)

## На земле (обязательно)

- [ ] Прошивка ArduCopter загружена, версия записана
- [ ] Калибровка акселерометра (все оси)
- [ ] Калибровка компаса (вдали от металла/магнитов)
- [ ] Калибровка пульта (мин/макс/trim, failsafe RC на приёмнике)
- [ ] Level horizon / AHRS ориентация совпадает с рамой
- [ ] Моторы: правильный порядок и направление (Motor Test)
- [ ] Пропеллеры сняты на время мотор-теста и проверки ARM
- [ ] GPS: ≥6 спутников, HDOP приемлемый перед ARM в GPS-режимах
- [ ] Failsafe RC проверен: отключение пульта → ожидаемое действие (RTL/Land)
- [ ] Напряжение батареи корректно в HUD; пороги `BATT_*` под вашу АКБ
- [ ] Параметры записаны (`Write Params`), контроллер перезагружен

## Первый вылет

- [ ] Открытая площадка, без людей в зоне пропеллеров
- [ ] Режим Stabilize или AltHold
- [ ] Короткий hover 30–60 с, проверить дрейф и вибрации
- [ ] Лог `.bin` скачан и просмотрен (Vibe, Mag, Power)

## После первого вылета

- [ ] При сильных вибрациях — демпфер FC / баланс пропов
- [ ] При дрейфе по yaw — компас / интерференция силовых проводов
- [ ] Подстройка `tuning-soft.param` по ощущениям и логам
