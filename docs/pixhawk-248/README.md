# Pixhawk 2.4.8 — обзор настройки

## Железо

- Полётный контроллер: **Pixhawk 2.4.8** (FMUv2)
- Типичный GPS: u-blox M8N / аналог на UART (обычно `GPS` / Serial3)
- Питание: модуль питания на `POWER` (измерение тока/напряжения)
- Приёмник: SBUS / PPM / CRSF — порт `RCIN` или соответствующий UART

Полная инструкция «кабель → программа → прошивка → параметры»: **[flash-and-setup.md](flash-and-setup.md)**.

## Рекомендуемый порядок

1. **Прошивка** — ArduCopter (стабильный релиз), не бета, если нет особой нужды.
2. **Каркас** — `FRAME_CLASS=1` (Quad), `FRAME_TYPE=1` (X) для классического квада X.
3. **Калибровки** — Accel, Compass, Radio, Level (горизонт).
4. **Параметры** — файлы из `/params` (см. корневой README).
5. **Моторы** — порядок и направление по схеме Mission Planner Motor Test.
6. **Failsafe** — RTL при потере RC/GPS (файл `failsafe-gps.param`).
7. **Первый полёт** — Stabilize / AltHold на открытой площадке, низкий газ.

## Что меняет каждый файл параметров

### `quad-x-baseline.param`

Каркас, логирование, базовая ориентация компаса, серийные порты GPS, пороги ARM.

### `failsafe-gps.param`

Поведение при потере связи и GPS: RTL, высота возврата, geofence (по желанию ослабьте/отключите).

### `tuning-soft.param`

Консервативные ATC/PSC значения для первого вылета. После стабильного зависания подкрутите по логам.

## Частые правки «под себя»

| Цель | Параметры |
|------|-----------|
| Высота RTL | `RTL_ALT` (см) |
| Скорость RTL | `RTL_SPEED` |
| Низкий заряд → RTL/Land | `BATT_FS_LOW_ACT`, `BATT_LOW_VOLT` |
| Жёстче/мягче Stabilize | `ATC_ANG_*`, `ATC_RAT_*` |
| Дальность GPS-режимов | качество GPS + `GPS_TYPE`, компас |
| Режим по умолчанию | `FLTMODE1`…`FLTMODE6` под тумблеры пульта |

## PX4

Если используете **PX4**, эти `.param` ArduPilot **не подходят**. Нужен отдельный airframe + QGC parameters. Напишите стек явно — подготовим другой набор.
