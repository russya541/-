# 03. Запрос ТУ: подтверждение 75 кВт и увеличение мощности

Два шаблона: (1) подтверждение существующей мощности и переоформление абонента; (2) заявка на увеличение разрешённой мощности для мойки и будущих ЭЗС.

Подавать в энергоснабжающую организацию региона (РЭС / филиал Гродноэнерго), обслуживающий г. Лида. Точный адрес и перечень приложений уточнить на месте или на сайте организации.

```
3. Копия договора купли-продажи НЗКС / выписка ЕГРНИ (после сделки
   или предварительный договор — по требованию).
4. Имеющиеся ТУ / акты разграничения (от продавца).
```

```
Прошу выдать технические условия на увеличение разрешённой

Существующая разрешённая мощность: 75 кВт (уточнить по договору).
Требуемая мощность после увеличения: 200 кВт
  (допустимый диапазон запроса: 150–250 кВт).

Назначение объекта: мойка самообслуживания автомобилей
(4 поста), технический блок; на перспективу — зарядные станции
для электромобилей (AC и/или DC).

Категория по надёжности электроснабжения: [III / уточнить].
Напряжение: 0,4 кВ (при необходимости — 10 кВ по рекомендации РЭС).

Прошу указать в ТУ:
- возможность увеличения до запрошенной мощности;
- перечень работ на сетях энергосистемы (кабель, ТП, ячейки);
- ориентировочный срок и условия оплаты работ;
- требования к проектной документации потребителя.

Приложения:
1. Ситуационный план / генплан участка.
2. Расчёт электрических нагрузок (предварительный) — см. ниже.
3. Документы на участок / строение (по перечню организации).
4. Копия действующего договора электроснабжения.

Дата __________    Подпись __________
```

## Предварительный расчёт нагрузок (приложение к заявке)

| Потребитель | Ррасч., кВт | Примечание |
|-------------|-------------|------------|
| Мойка самообслуживания 4 поста | 35–45 | по паспорту оборудования |
| Нагрев воды / котёл | 15–30 | пик зимой |
| Тёплый пол постов (если есть) | 10–20 | сезонно |
| Пылесосы, освещение, админ | 5–10 | |
| Шиномонтаж лёгкий (фаза 2) | 5–15 | компрессор, станки |
| ЭЗС AC 2×22 кВт | 44 | не одновременно со всеми пиками |
| ЭЗС DC 1×60–120 кВт (фаза 2) | 60–120 | отдельный приоритет |
| **Запрашиваемый итог с запасом** | **150–250** | |

Для первой очереди (только мойка) достаточно подтверждённых **75 кВт** при грамотном проекте приоритетов. Увеличение нужно для комфортного запаса и ЭЗС.

## Ожидания по ответу РЭС

| Исход | Что делать |
|-------|------------|
| Мощность дают без тяжёлых работ на сетях | Заложить в бюджет небольшую плату + проект |
| Нужен кабель / ТП / реконструкция | Сравнить смету РЭС с выгодой ЭЗС; можно отложить DC |
| Резерва нет / отказ в запрошенном объёме | Согласовать меньшую мощность (например +50 кВт) или схему с ограничением одновременности |
| 75 кВт не подтверждается | Стоп-фактор до покупки или жёсткий торг по цене участка |

**Важно:** «дадут ли больше» решает техвозможность сетей ЖБИ, а не желание заявителя. Письменные ТУ — единственный надёжный ответ.
