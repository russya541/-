**Исходные данные**

- Локация: г. Лида, район ЖБИ, у дороги
- Площадь: ~50 соток
- Цена входа: ~$30 000 (право аренды 99 лет + фундамент НЗКС)
- Бюджет сверх покупки: $50–150 000
- Назначение: СТО + мойка
- На участке: вода, 75 кВт, фундамент (законсервирован, продление 3 года)

**Рекомендуемая стратегия:** сначала due diligence → покупка → мойка 3–4 поста → параллельно ТУ на мощность → фаза 2 (шиномонтаж/стоянка; быстрые ЭЗС только после ТУ).
