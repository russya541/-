# 02. Техническое задание: мойка самообслуживания 3–4 поста

Документ для передачи проектировщику и поставщику оборудования. Назначение участка: **СТО + мойка** — смена целевого назначения земли обычно не требуется; меняется проект объекта.

---

## 1. Цель проекта

Перепроектировать объект вместо «большого СТО + мойка» в:

**Основной объект:** бесконтактная мойка самообслуживания на **4 поста** (допустимо стартовать с 3 постов с заделом под 4-й).

**Опционально в контуре того же проекта (если влезает в бюджет):**

- 2–4 пылесоса самообслуживания
- небольшой админ/технический блок (котельная, склад химии, санузел)
- место под будущий лёгкий шиномонтаж (фаза 2, см. `04-faza-2.md`)

---

## 2. Исходные данные участка

| Параметр | Значение |
|----------|----------|
| Город | Лида, район ЖБИ |
| Площадь | ~50 соток (уточнить по кадастру) |
| Право | Аренда 99 лет (после покупки НЗКС) |
| Существует | Фундамент (законсервирован), вода, электро 75 кВт |
| Бюджет стройки+оборудования сверх покупки | $50–150 000 (целевой комфорт ~$100–150 000) |

---

## 3. Программа объекта (состав)

### 3.1. Обязательно

1. **4 поста** мойки самообслуживания (навесы, отбойники, разметка).
2. Техническое помещение: насосная, нагрев воды, склад химии, щитовая.
3. Система приёма оплаты (монетоприём / терминал / приложение — по КП поставщика).
4. **Очистные / оборотное водоснабжение** или схема, согласованная с водоканалом (критично).
5. Ливневая канализация площадки, уклоны к лоткам.
6. Освещение территории, видеонаблюдение (минимум 4–6 камер).
7. Въезд/выезд с дороги, разворотная схема без конфликта с потоком.

### 3.2. Желательно (если бюджет позволяет)

- Зона ожидания / навес для пылесосов (2–4 шт.)
- Тёплый пол / обогрев постов для зимы
- Ограда, шлагбаум или свободный въезд 24/7
- Место под 1–2 медленные ЭЗС AC 22 кВт (без быстрых DC)

### 3.3. Не включать в первую очередь

- Полноценное многопостовое СТО по старому проекту
- Быстрые DC-зарядки 60–120 кВт (фаза 2, после ТУ на мощность)
- Кафе / АЗС / склад «не под авто» (другая процедура назначения)

---

## 4. Инженерные нагрузки (ориентир)

| Система | Ориентир |
|---------|----------|
| Электроэнергия (мойка 4 поста) | 30–45 кВт оборудование |
| + нагрев воды / тёплый пол | +15–40 кВт пиково |
| + освещение, пылесосы, админ | +5–10 кВт |
| **Итого в лимите 75 кВт** | Да, при приоритизации нагрузок и грамотном проекте |
| Вода | по паспорту оборудования (~0.8–1.2 м³/ч на пост) |
| Канализация / очистка | обязательно в проекте |

Проектировщику: заложить **приоритеты отключения** некритичных нагрузок, чтобы не превышать 75 кВт. Параллельно заказчик запрашивает ТУ на увеличение (см. `03-zayavka-moschnost.md`).

---

## 5. Использование существующего фундамента

Порядок:

1. Техническое обследование фундамента (заключение).
2. Если оси/нагрузки совместимы с постами мойки — использовать / частично использовать.
3. Если фундамент под «большое СТО» и мешает генплану мойки — предусмотреть демонтаж и новые основания (отдельная смета).

В задании проектировщику явно указать: **приоритет — оптимальный генплан мойки и подъездов, а не «спасти фундамент любой ценой»**.

---

## 6. Порядок согласований (Беларусь)

1. Решение о расконсервации / возобновлении строительства.
2. Заключение о техсостоянии фундамента.
3. Задание на проектирование (этот документ) → договор с проектировщиком.
4. Эскиз / предпроект — согласование архитектуры исполкома.
5. Проектная документация (+ экспертиза при необходимости по классу сложности).
6. Разрешение на строительство.
7. СМР, пусконаладка оборудования.
8. Ввод в эксплуатацию, регистрация завершённого строения.

Срок «от покупки до открытия» закладывать **6–14 месяцев** (зависит от экспертизы и стройки).

---

## 7. Требования к поставщику оборудования

Запросить КП минимум у **2–3** поставщиков (примерный состав комплекта):

- Моечные посты (пистолеты, пена, воск, ополаскивание)
- Насосная станция, нагрев воды
- Система управления и оплаты
- Пылесосы (опция)
- Гарантия, сервис в регионе (Гродно / Минск с выездом)
- Обучение, расходники на 1–3 месяца

Сравнить: цена, гарантия, наличие запчастей, отзывы действующих моек в РБ.

---

## 8. Генплан (логика зонирования ~50 соток)

Не обязательно занимать весь участок мойкой.

```
[Дорога]
   | въезд
   v
+------------------+     +------------------+
| Мойка 4 поста    |     | Пылесосы / админ |
+------------------+     +------------------+
         |
   [технический блок]
         |
+------------------------------------------+
| Резерв фазы 2: шиномонтаж / стоянка / ЭЗС|
| (свободная площадь)                      |
+------------------------------------------+
```

Свободную часть не бетонировать «в ноль» сразу — оставить под фазу 2.

---

## 9. Критерии приёмки проекта

- [ ] Согласовано архитектурой
- [ ] Электрическая нагрузка ≤ 75 кВт или есть ТУ на увеличение
- [ ] Схема стоков согласована
- [ ] Смета в бюджете заказчика
- [ ] Предусмотрен задел под 3→4 пост (если старт с 3)
- [ ] Зона фазы 2 не перекрыта капитальными сооружениями без нужды
