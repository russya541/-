# 06. Пошаговый чеклист запуска

Сводка всех этапов от проверки до открытия и фазы 2.

---

## Этап 0. До покупки

- [ ] Пройти чеклист [`01-due-diligence.md`](01-due-diligence.md)
- [ ] Замер трафика 3–7 дней
- [ ] Устное/письменное мнение архитектуры: мойка самообслуживания ок
- [ ] КП от 2–3 поставщиков моек + ориентир стройки
- [ ] Решение: покупать / торговаться / отказаться

## Этап 1. Сделка

- [ ] Договор купли-продажи НЗКС (фундамент)
- [ ] Госрегистрация прав на строение и аренду
- [ ] Переоформление воды и электричества
- [ ] Папка объекта: все оригиналы/сканы

## Этап 2. Мощность (параллельно)

- [ ] Подать подтверждение 75 кВт — [`03-zayavka-moschnost.md`](03-zayavka-moschnost.md)
- [ ] Подать запрос увеличения до 150–250 кВт
- [ ] Получить ТУ, оценить стоимость
- [ ] Решение по ЭЗС отложить до цифр ТУ

## Этап 3. Проект мойки

- [ ] Выдать ТЗ проектировщику — [`02-tz-moika.md`](02-tz-moika.md)
- [ ] Обследование фундамента
- [ ] Расконсервация / возобновление строительства
- [ ] Согласование архитектуры
- [ ] Проект + экспертиза (если нужна)
- [ ] Разрешение на строительство
- [ ] На генплане оставить зону фазы 2

## Этап 4. Строительство и запуск

- [ ] Договор с подрядчиком СМР
- [ ] Договор на оборудование мойки
- [ ] Монтаж, пусконаладка, обучение
- [ ] Ввод в эксплуатацию
- [ ] Касса / терминалы / учёт
- [ ] Вывеска, навигация с дороги, Яндекс/Google карты
- [ ] Открытие

## Этап 5. Фаза 2 (после стабилизации)

- [ ] Следовать [`04-faza-2.md`](04-faza-2.md)
- [ ] Шиномонтаж или стоянка — по спросу
- [ ] AC-зарядки — по остатку мощности
- [ ] DC — только при ТУ и экономике
